# Training launchers

- `env.sh`: loads local training configuration and environment defaults.
- `run-qwen3-4B-miu.sh` / `run-qwen3-4B-eil.sh`: launch one mechanism inside the training environment.
- `run_training_container.sh`: starts the pinned SLIME container for one mechanism.
- `run_loyal_smoke.sh`: runs the short MIU-to-EIL smoke chain.
- `start_judge_tcp_proxy.sh`: starts the optional host-side judge TCP relay.
